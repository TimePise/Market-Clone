# 당근마켓 클론 프로젝트 (Daangn Market Clone)

당근마켓의 메인 페이지를 클론 코딩한 프로젝트입니다.

## 📱 프로젝트 소개

이 프로젝트는 한국의 대표적인 중고거래 플랫폼인 당근마켓의 모바일 웹 UI를 HTML과 CSS만을 사용하여 구현한 클론 프로젝트입니다.

## 🚀 데모

[GitHub Pages에서 확인하기](https://timepise.github.io/Market-Clone/당근마켓.html)

## 🛠 기술 스택

- HTML5
- CSS3
- Pretendard 폰트

## 📂 프로젝트 구조

```
Market-Clone/
├── 당근마켓.html          # 메인 HTML 파일
├── 당근마켓/
│   ├── style.css         # 메인 스타일 파일
│   ├── reset.css         # CSS 리셋
│   ├── header.css        # 헤더 스타일
│   ├── main.css          # 메인 콘텐츠 스타일
│   └── footer.css        # 푸터 네비게이션 스타일
└── 당근마켓 assets/        # 아이콘 및 이미지 파일들
```

## ✨ 주요 기능

### 1. 헤더 (Header)
- 상단 정보바 (시간, 배터리, Wi-Fi 등)
- 위치 선택 메뉴 (역삼1동)
- 검색, 메뉴, 알림 아이콘

### 2. 메인 콘텐츠 (Main)
- 중고거래 아이템 리스트
- 각 아이템별 이미지, 제목, 지역, 시간, 가격 정보 표시
- 고정된 글쓰기 버튼 (우측 하단)

### 3. 푸터 네비게이션 (Footer)
- 홈
- 동네생활
- 내 근처
- 채팅
- 나의 당근

## 🎨 디자인 특징

- **모바일 퍼스트**: 모바일 화면에 최적화된 반응형 디자인
- **고정 요소**: 헤더와 푸터가 고정되어 스크롤 시에도 항상 표시
- **Flexbox 레이아웃**: 현대적인 CSS Flexbox를 활용한 레이아웃 구성
- **그림자 효과**: 글쓰기 버튼에 부드러운 그림자 적용
- **브랜드 컬러**: 당근마켓의 시그니처 오렌지 컬러 (#fe6f0f) 사용

## 📝 CSS 구조

### reset.css
- Eric Meyer의 CSS Reset을 사용하여 브라우저 기본 스타일 초기화

### header.css
- 정보바와 메뉴바 스타일링
- Flexbox를 활용한 정렬

### main.css
- 아이템 리스트 레이아웃
- 글쓰기 버튼 스타일링 (고정 위치)

### footer.css
- 하단 네비게이션 바
- 5개의 메뉴 아이콘과 설명 배치

## 🔧 로컬에서 실행하기

1. 저장소 클론
```bash
git clone https://github.com/TimePise/Market-Clone.git
```

2. 프로젝트 디렉토리로 이동
```bash
cd Market-Clone
```

3. HTML 파일 열기
- `당근마켓.html` 파일을 브라우저에서 열기

또는 Live Server 등의 개발 서버 사용
